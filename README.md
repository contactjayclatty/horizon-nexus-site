# Horizon Nexus website

**Extend the Engine. Connect the Systems.** Built Block by Block.

The website for Horizon Nexus, the Rust-native modding framework and mod loader for the [Horizon](https://github.com/horizon-rust/horizon) engine. Live at **https://contactjayclatty.github.io/horizon-nexus-site/**.

Nexus status (developer-reported, from an independent development branch; not verified against public upstream): v0.1 core runtime and lifecycle, v0.2 world events and command integration, v0.3 typed event bus and deterministic dispatch, v0.4a manifest discovery and dependency resolution, the pre-v0.4b audit and v0.4b.1 native mod registration foundations are complete. v0.4b.2 (secure package loading and installation foundations) is in development: checkpoints 3.1 to 4.2c-b are complete (archive validation, SHA-256 identity, CRC-32 metadata, private custody, extraction planning and a cap-std filesystem boundary), 115 internal tests pass at the latest verified checkpoint (94 loader, 21 runtime), and actual ZIP extraction and mod installation are not implemented yet. v0.4c, v0.4d and a final hardening stage are planned. No public Nexus binary, installer or .nmod download exists.

## Stack

Plain HTML, CSS and JavaScript generated by `build.mjs` (Node 22+, standard library only), the same approach as Horizon's own site. No framework and no runtime dependencies. This was chosen over Astro because it matches Horizon's site structure directly and keeps the build dependency-free.

```sh
node build.mjs                 # dist/ with base /horizon-nexus-site/ (BASE=/ for a root domain)
node serve.mjs                 # http://localhost:4321/horizon-nexus-site/
node --test tests/*.test.mjs   # build, links, metadata, honesty, secrets, contrast
```

## Layout

```
build.mjs, serve.mjs     build and local server
src/                     tokens.css, style.css, site.js, icons.mjs (pixel icons), content.mjs (every Nexus claim), docs.mjs
scripts/                 art.mjs (pixel art), png.mjs, raster.mjs (icons, og.png), qa.mjs (browser QA)
public/                  fonts (OFL), favicon, og.png, media (logo, icon, portal)
tests/                   node:test checks
docs/design/             horizon-reference.md, visual-review.md, site-improvement-audit.md
.github/agents/          the seven Nexus Development Collective profiles
.github/workflows/       GitHub Pages deployment
```

Deployment: every push to `main` runs `.github/workflows/pages.yml`, which tests, builds and publishes to GitHub Pages.
